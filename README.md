# Situated Inference — Ameca humanoid demo

Static demo page for *Situated Inference: Adapting Frozen Generative Speech Enhancement under Acoustic Distribution Shift* (anonymous submission).

- `index.html` — generated by `python3 build_page.py` from `site.json` (all page text) and `robot/manifest.json`
- `robot/video`, `robot/poster`, `robot/audio` — per-clip assets (90 clips: 4 backbones × utterances × {default, quality, efficiency}); videos carry a keyframe every 0.5 s so synced playback and scrubbing seek cleanly
- `robot/manifest.json` — per-clip timings (measured GPU compute, observed pause, clip-relative phase boundaries)
- `assets/` — hero cover frame and the bundled Charter font

Layout adapted from [Clarity](https://shikun.io/projects/clarity) (CC0). Local preview needs a server with HTTP Range support for video scrubbing.
